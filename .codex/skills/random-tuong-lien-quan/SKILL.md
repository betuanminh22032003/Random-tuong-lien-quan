# RandomTuong.vn

## Quick Orientation

Use this skill for project-specific work in `E:\code\Random-tuong-lien-quan`.

- `src/pages/index.tsx`: main randomizer, 5v5 team generator, ban/pick, meta table, SEO tags.
- `src/pages/tuong/[slug].tsx`: static hero detail pages generated from `HEROES`.
- `src/data/heroes.ts`: canonical typed hero data consumed by Next.js.
- `heroes-data.js`: legacy browser-global data generated by the crawler.
- `scripts/crawl-garena-heroes.mjs`: Garena crawler that rewrites both data files.
- `src/styles/globals.css`: global layout and component styling.

## Workflow

1. Read `AGENTS.md` first for persistent project rules.
2. Inspect the exact page/data/script involved before editing.
3. Keep edits scoped to the request and preserve static export compatibility.
4. Run `npm.cmd run build` after code, route, SEO, or data-shape changes.
5. For data refreshes, run `node scripts/crawl-garena-heroes.mjs`, then spot-check generated output.

## Data Rules

- Garena-sourced fields: hero names, official roles, image URLs, source URLs, skill names, and skill descriptions.
- App metadata: `tier`, `winrate`, `difficulty`, `lane`, `emoji`, `role`, and `secondaryRole`.
- Do not describe app metadata as official Garena winrate or balance data.
- Keep `src/data/heroes.ts` and `heroes-data.js` aligned. Prefer rerunning the crawler when broad hero data changes are needed.
- Preserve `slugify` behavior unless explicitly changing URL strategy; it drives `/tuong/[slug]/` paths.

## Frontend Rules

- Keep the randomizer as the first-screen experience.
- Keep Vietnamese labels natural and short.
- Maintain mobile usability for filters, tabs, hero cards, ban/pick slots, and team grids.
- Avoid marketing-style landing-page rewrites unless explicitly requested.
- Do not remove AdSense or analytics placeholders unless the task asks for it.

## Useful Commands

- Use `npm.cmd` and `npx.cmd` on Windows because PowerShell may block `.ps1` shims.
- Build: `npm.cmd run build`
- Crawl: `node scripts/crawl-garena-heroes.mjs`
- Read bracketed route files with `Get-Content -LiteralPath src\pages\tuong\[slug].tsx`.
